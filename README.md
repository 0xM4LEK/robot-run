# 🤖 Robot Run

**Robot Run** is a retro-style, cyber-themed endless runner built with HTML, CSS and JavaScript. Dodge obstacles, survive increasingly difficult levels, fight bosses, and try to make it through all 35 levels.

The game runs directly in your browser — no installation required.

## ✨ Features

- **35 levels** with progressively increasing difficulty.
- **7 boss fights** with different attacks and mechanics.
- **Endless mode** unlocked after completing all 35 levels.
- **Jump, duck and shoot** to survive obstacles and enemies.
- **Charged shots** for more powerful attacks.
- **Combo scoring system** with multipliers and close-call bonuses.
- **Level practice** — start from previously unlocked levels.
- **Retro pixel-style graphics** with a cyber-themed aesthetic.
- **Day and night visual themes.**
- **Sound effects and dynamic boss music.**
- **Local score saving** — your records are saved in your browser.
- **Responsive controls** supporting keyboard, mouse and touch.

## 🕹️ Controls

| Action | Controls |
|---|---|
| Jump | `↑` / `Space` / Left Click |
| Duck | `↓` |
| Fire | `F` / `X` / `Z` / `→` / Right Click |
| Charge Shot | Hold the fire button |
| New Game | `N` |
| Endless Mode | `E` after completing the game |

### Touch Controls

- Tap to jump.
- Hold the lower part of the screen to duck.
- Use the fire button to shoot.
- Hold the fire button to charge a stronger shot.

## 🏆 Gameplay

Your goal is to survive obstacles, build combos, earn points and progress through increasingly challenging levels.

- Every 5 levels, you face a boss.
- Defeating bosses rewards bonus points and progression.
- Close calls reward extra points and increase your combo multiplier.
- You can earn additional hearts as you progress.
- Complete all 35 levels to unlock Endless Mode.

## 🛠️ Built With

## 🚀 Run Locally

1. Download `index.html`.
2. Open the file in your browser.
3. Start playing!

No installation or external dependencies are required.
